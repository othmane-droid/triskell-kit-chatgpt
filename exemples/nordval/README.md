# Le cas fictif Nordval Énergie

Nordval Énergie n'existe pas. Ces fichiers servent à essayer les prompts P, X et Z sans aucune donnée réelle.

- `cas2-*` : le modèle PowerPoint, le compte rendu du comité et l'export des tickets.
- `resultats/` : des exemples préparés avec Claude, pas avec ChatGPT. Ils montrent le niveau attendu. Vos résultats peuvent différer : comparez-les aux points « Vérifiez » de chaque prompt.
